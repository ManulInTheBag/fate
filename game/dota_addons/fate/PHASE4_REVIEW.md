# Фаза 4: ассеты-кандидаты на удаление — НА РЕВЬЮ

**Ничего ещё не удалено.** Это отчёт анализатора достижимости ассетов
(`asset_analyzer.py`): корни = scripts (lua/kv/txt) + panorama-исходники +
скомпилированная panorama + карты (vpk/vmap strings) + спеллаиконки по
`AbilityTextureName` + портреты по herolist; затем BFS по строкам внутри
живых бинарников (vpcf→child, vmdl→vmat→vtex, vsndevts→vsnd) до фикспоинта,
с консервативными правилами (папка живой модели целиком; twin-пары
content↔game по имени; звук жив, если упомянут хоть одним vsndevts).

**Whitelist уже применён** (не кандидаты): Kirei/Rasputin, Cu Chulainn Alter,
loadscreen/loading (49 файлов удержано).
