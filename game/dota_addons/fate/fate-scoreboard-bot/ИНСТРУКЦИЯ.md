# Инструкция по боту

## Включить / выключить
- **Включить:** дважды кликни ярлык **Fate Bot** (или `Start Bot.bat`).
  Откроется окно — пока оно открыто, бот работает.
- **Выключить:** закрой окно.

Бот работает только пока окно открыто и компьютер включён. При первом запуске
загружаются модели распознавания (в окне появится `EasyOCR models ready`).

---

## Как это работает
1. Игрок выкладывает **скриншот таблицы** в игровом канале.
2. Бот молча читает его и присылает разобранную таблицу **в твой управляющий
   канал** (в игровом канале бот ничего не пишет).
3. Ты проверяешь её там:
   - **✅** сохранить · **❌** удалить · **ответить** чтобы исправить, потом ✅

### Исправление ячеек (ответь на сообщение бота)
Одна правка — одна строка. Имена с пробелами — в кавычках.

| Напишешь | Что сделает |
|----------|-------------|
| `row6 k=5` | убийства (K) в строке 6 |
| `row6 k=5 d=13 a=32` | K / D / A в строке 6 |
| `row1 player="某個索引信使"` | исправить имя игрока |
| `row3 hero="Oda Nobunaga"` | исправить героя |
| `score 12-6` | исправить счёт |
| `winner top` | кто победил (`top` / `bottom`) |

Поля: `k` — убийства, `d` — смерти, `a` — помощь, `player` — игрок, `hero` — герой.

## Статистика — `%export`
Создаёт файл Excel и присылает его в управляющий канал.

| Команда | Что выгрузит |
|---------|--------------|
| `%export` | всё за всё время |
| `%export today` / `yesterday` / `week` / `month` | по времени |
| `%export 7d` / `24h` / `90m` | за N дней / часов / минут |
| `%export last 5` | последние 5 игр |
| `%export from 2026-06-01 to 2026-06-10` | за период дат |
| `%export games 10-25` / `game 14` | по номеру игры |

**`%report N`** — быстро: подтянет последние игры из канала **и** выгрузит
последние N за один раз (например `%report 10`).

## Просмотр
| Команда | Что покажет |
|---------|-------------|
| `%matches` | последние игры и их **номера** |
| `%players` | всех игроков и сколько у них игр |
| `%help` | краткая справка в Discord |

## Объединить одного игрока — `%alias` / `%links`
Для разных аккаунтов или имён, по-разному распознанных — считать их за одного.

| Команда | Что сделает |
|---------|-------------|
| `%alias "Распознанное" "Настоящее"` | считать распознанное имя за настоящего игрока |
| `%alias "Распознанное" = "Настоящее"` | то же самое, через `=` (тоже работает) |
| `%alias` | показать все связки |
| `%unalias "Распознанное"` | убрать связку |
| `%links` | бот сам предложит похожие имена |
| `%links apply` | применить все предложения |

Имена с пробелами — в кавычках. Пример: `%alias "Ъ" "b"` или `%alias "cute Iute" "cute lute"`.

`%links` находит похожие имена автоматически. Сложные случаи (латиница,
распознанная как кириллица, или ник vs полное имя) он не видит — найди их через
`%players` и свяжи вручную через `%alias`.

## Удаление данных
**`%clear`** — удалить игры по диапазону (в два шага, нужен `confirm`):

| Команда | Что сделает |
|---------|-------------|
| `%clear all` | предпросмотр (ничего не удаляет) |
| `%clear all confirm` | удалить всё |
| `%clear game 14 confirm` · `%clear games 10-25 confirm` | по номеру |
| `%clear today confirm` · `%clear from … to … confirm` | по времени |

**`%cleanup`** — убрать игры, которые не являются таблицами Fate (неверный формат
или плохо распознанные). `%cleanup` покажет количество, `%cleanup confirm` удалит.

---

## Импорт старых игр — `%backfill`
Читает скриншоты, выложенные **до запуска бота**. Можно запускать повторно
(уже импортированные пропускаются), сохраняет исходную дату каждой игры.

| Команда | Что сделает |
|---------|-------------|
| `%backfill` | последние 200 сообщений |
| `%backfill all` | всю историю канала |
| `%backfill after 2026-05-01` | всё начиная с даты |

Прогресс виден в окне бота. EasyOCR точный, но медленный, поэтому большой импорт
займёт время.

## Что происходит автоматически
- **Герои** подгоняются к настоящему списку из 51; нечитаемые → `Unknown`.
- **Китайские таблицы** поддерживаются — китайские имена героев переводятся в
  английские.
- **Неверные форматы** (внутриигровая таблица по Tab, мемы, скрины чата)
  пропускаются автоматически; в окне будет `✗ ignored`.
- **Игроки** объединяются по твоим `%alias` / `%links`.

## Обычный порядок
✅ каждую игру по мере появления → иногда `%players` чтобы найти дубли →
`%alias` для них → `%export today` (или `%report 10`) для Excel.
